# Shanghai 2050 · A Week of Urban Metabolism

Latest static edition prepared on 5 November 2026 from the working artwork.

Open the site to start on the English home page. Select EXPLORE MY WORK or Shanghai
on the globe to enter the city. Time advances automatically while viewing the city;
the pause button freezes it. Seeking and choosing a day preserve the playback state.
Returning home and entering again preserves the week position. EN / 中文 remains available.
The interaction selector stays beside the sound control in both views.

## GitHub Pages

Publish the contents of this directory at the root of the main branch. Keep assets/,
data/, vendor/ and week/ beside index.html. No build step or npm install is required.
The existing Pages site is https://tian-alt-ux.github.io/shanghai-2050-art/ .

## Camera gestures

The public edition supports mouse and touch interaction. GESTURES opens an explanation
of the local software requirement. Connecting a Femto Bolt by USB alone does not enable
depth gestures in this static site. Depth acquisition and hand recognition currently
run in a separate local program; this public edition does not connect to that program.
No camera images, camera runtime, control tokens or private logs are included here.
The existing local installation retains the tested single-hand depth controls.

## Future Echoes

Curated vision cards can be browsed. Shared submissions require a separately hosted
API and persistent storage; GitHub Pages does not provide the local api/echoes service.
An unsuccessful submission keeps the draft on the visitor's device.
